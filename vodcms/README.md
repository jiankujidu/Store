# 影视中心 (vodcms)

飞牛 NAS 原生影视 CMS 应用，提供影视后台管理与安卓客户端开放接口。

## 功能
- 后台管理：分类 / 影片 / 剧集 / 多线路播放源管理
- 开放接口：对接苹果CMS 协议片源，供安卓客户端拉取
- APK 下载页：内置安卓客户端下载入口
- 数据持久化：存储在飞牛持久化数据目录，重装不丢

## 默认账号
- 地址：`http://<飞牛IP>:<端口>/app/vodcms`
- 管理员：`admin` / `admin123`（首次启动自动创建，请尽快修改）

## 端口
由飞牛应用中心安装时分配（默认 15666），无需手动配置。

## 说明
- 后端基于 Node.js（飞牛 `nodejs_v24` 依赖应用）+ Express5 + node:sqlite
- 片源对接：在后台「系统设置」填写苹果CMS API 地址即可
