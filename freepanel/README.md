# 七玄Panel

免费开源的 NAS / 浏览器导航面板，可作为 sun-panel 类应用的免费替代。数据以 JSON 文件持久化，**无需数据库**，单 jar 运行。

## 功能

- 导航卡片管理：分类 + 链接，支持图标（iconify）、内网/外网双地址一键切换
- 系统状态监控：CPU / 内存 / 运行时长 / 磁盘（JMX）
- 天气与时钟小部件：Open-Meteo 免费接口，无需 Key
- 主题外观：多主题、深浅色、自定义 CSS / JS
- 多账户隔离：共享设置 + 每账户独立分类/设置，PBKDF2 密码哈希
- 全局搜索框，支持多引擎

## 安装

在飞牛 NAS **应用中心 → 设置 → 添加第三方应用源** 填入本源地址后，于应用列表安装「七玄Panel」。

也可手动安装：下载 `freepanel.fpk` 后，通过应用中心「手动安装」上传，或执行
`appcenter-cli install-fpk freepanel.fpk`。

## 首次使用

1. 安装后应用会自动启动；首次启动若系统无 Java，会自动安装 `openjdk-17-jre-headless`（需 NAS 联网）。
2. 默认管理员账户：`admin` / `admin`。
3. 访问方式（二选一）：
   - 点击飞牛桌面的「七玄Panel」图标（经 `/app/freepanel` 反代打开）；
   - 浏览器直接访问 `http://<NAS IP>:47960`（端口以安装时飞牛实际下发的为准，默认 47960）。
4. 进入控制台后请立即修改默认密码。

## 数据与备份

- 数据保存在应用数据目录（`${PKGVAR}/data`）：`settings.json`、`users.json`、`sessions.json` 及各账户的 `categories.json` / `settings.json`。
- 卸载应用不会自动删除该数据目录；升级会保留。
