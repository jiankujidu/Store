# 七玄Panel

免费开源的 NAS / 浏览器导航面板，可作为 sun-panel 类应用的免费替代。数据以 JSON 文件持久化，**无需数据库**，单 jar 运行。

## 功能

- 导航卡片管理：分类 + 链接，HTML5 拖拽排序（分类内排序 + 跨分类移动）、中键/右键新窗口打开、iframe 小窗预览
- 内网/外网双地址：每个链接可分别配置内网与外网地址，顶栏一键切换可见范围，右键菜单可选地址打开
- 图标系统：iconify 名称、本地上传、图库选择、favicon 一键获取；支持图标背景色与圆形/方形样式
- 搜索引擎：搜索框多引擎下拉切换，控制台可自定义增删改搜索引擎
- 系统状态监控：CPU / 内存 / 运行时长 / 磁盘（JMX）
- 天气与时钟小部件：Open-Meteo 免费接口，无需 Key
- sun-panel 原版界面：全屏壁纸（模糊+缩放+暗色遮罩）、大标题+分隔符+时钟、搜索框、监控卡片行、分组宫格、右下悬浮按钮组；图标支持宫格/详情双形态，控制台「面板外观」可调标题/模糊/遮罩/边距/宽度/图标样式与文字色
- Docker 面板：容器列表、启动/停止/重启（Docker Engine API，控制台配置 endpoint）
- 图库/文件管理：图片上传（图标/壁纸分类）、删除、复制外链、一键设为壁纸
- 主题外观：多主题、深浅色、自定义 CSS / JS、页脚自定义文本
- 多账户隔离：共享设置 + 每账户独立分类/设置，PBKDF2 密码哈希
- 公开模式：开启后未登录访客可只读浏览面板
- 会话时长可配置（默认 168 小时）
- 加载性能：本地缓存优先渲染 + 骨架屏

## 安装

在飞牛 NAS **应用中心 → 设置 → 添加第三方应用源** 填入本源地址后，于应用列表安装「七玄Panel」。

也可手动安装：下载 `freepanel.fpk` 后，通过应用中心「手动安装」上传，或执行
`appcenter-cli install-fpk freepanel.fpk`。

## 首次使用

1. 安装后应用会自动启动；首次启动若系统无 Java，会自动安装 `openjdk-17-jre-headless`（需 NAS 联网）。
2. 默认管理员账户：`admin` / `admin`。
3. 访问方式（二选一）：
   - 点击飞牛桌面的「七玄Panel」图标，浏览器新标签页打开 `http://<NAS IP>:47960`；
   - 浏览器直接访问 `http://<NAS IP>:47960`（端口以安装时飞牛实际下发的为准，默认 47960）。
4. 进入控制台后请立即修改默认密码。

## 数据与备份

- 数据保存在应用数据目录（`${PKGVAR}/data`）：`settings.json`、`users.json`、`sessions.json` 及各账户的 `categories.json` / `settings.json`。
- 卸载应用不会自动删除该数据目录；升级会保留。
